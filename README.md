
# VIDE AI 

VIDE AI is an AI-powered learning platform designed to help students study smarter, stay focused, and improve their learning experience. The frontend provides an interactive interface where students can access learning tools, navigate their dashboard, and manage their study activities.

## Features

- **Landing Page** — Introduces VIDE AI and its learning features.
- **Authentication Pages** — Sign-in, sign-up, and email verification interfaces.
- **AI Chat** — A dedicated interface for AI-assisted learning and study conversations.
- **Flash Cards** — A section for revision and memorization.
- **Focus Timer** — An interface for managing focused study sessions.
- **Study Profile** — A section for personal study information and progress.
- **Responsive Design** — Adapts to desktop and mobile screens.

##  Technologies Used

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- React Icons




##  Frontend Structure

The frontend is organized into reusable React components and sections to make the application easier to maintain and extend.

- **Pages:** Landing page and authentication pages.
- **Dashboard:** Main dashboard layout and navigation.
- **Section Components:** Chat, Flash Cards, Focus Timer, and Study Profile.
- **Styling:** Tailwind CSS and custom theme variables.

##  Project Status

The frontend is under active development. The main pages, dashboard layout, navigation, and study section interfaces are being developed, with some interactions and features still requiring implementation.
